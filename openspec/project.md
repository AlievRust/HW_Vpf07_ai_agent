# Проект: Терминальный AI-агент

## Назначение
Python-приложение, которое запускается из терминала или Telegram, понимает задачи на естественном языке и выбирает подходящие инструменты для поиска информации, работы с файлами, ограниченных терминальных команд, получения погоды, цен криптовалюты, курсов обычных валют и напоминаний по расписанию.

## Цели
- Дать пользователю удобного AI-агента для терминала.
- Обеспечить OpenAI-совместимый интерфейс подключения.
- Сохранять долговременную память диалога в JSON-файл.
- Поддерживать безопасный доступ к файловой системе и shell-командам.
- Использовать внешние API только через явные инструменты.
- Поддерживать напоминания и повторяющиеся расписания через локальный JSON-файл.
- Поддерживать Telegram polling-бота как альтернативный интерфейс к тому же ядру.

## Ограничения
- Только Python 3.10+.
- Только OpenAI-совместимый API с настройкой через `.env`.
- Безопасный shell без `shell=True` и без произвольных опасных команд.
- Файловые операции только внутри workspace.
- Все ответы и документация для пользователя должны быть на русском языке.
- Напоминания хранятся локально в JSON и могут быть показаны пользователю при следующем запуске агента.
- Telegram-бот использует то же ядро, что и CLI, без раздельных пользовательских профилей.
