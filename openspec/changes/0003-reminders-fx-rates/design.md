# Текущее поведение
Агент умеет web search, HTTP-запросы, файловые операции, ограниченные терминальные команды, погоду и криптовалюту.

Напоминания не поддерживаются.
Курсы обычных валют не поддерживаются отдельным инструментом.

# Целевое поведение
Агент работает с двумя новыми группами возможностей:

1. Напоминания
- можно создать напоминание на конкретную дату и время;
- можно создать повторяющееся напоминание с фиксированным интервалом в минутах;
- напоминания сохраняются в JSON-файле;
- при каждом запуске или обработке запроса агент извлекает просроченные напоминания;
- одноразовые напоминания помечаются завершёнными после срабатывания;
- повторяющиеся напоминания сдвигаются на следующий интервал после срабатывания;
- пользователь может посмотреть список напоминаний и отменить их.

2. Курсы валют
- можно получить актуальный курс между обычными валютами;
- приоритетные коды: `EUR`, `USD`, `RUB`;
- инструмент поддерживает запрос одного курса или нескольких курсов к одной базе.

Также:
- при срабатывании напоминаний агент показывает их пользователю в CLI;
- новые возможности доступны через тот же агентный цикл и существующий интерфейс запуска.

# Изменения модели данных
`agent/reminders.json` хранит список записей напоминаний.

Каждая запись содержит:
- `id`;
- `title`;
- `notes`;
- `created_at`;
- `next_run_at`;
- `repeat_every_minutes`;
- `last_fired_at`;
- `status`.

Статусы:
- `active`;
- `completed`;
- `cancelled`.

# Изменения API
Добавляются новые инструменты:
- `create_reminder`
- `list_reminders`
- `cancel_reminder`
- `get_currency_rates`

`get_currency_rates` использует внешний HTTP API без ключа.

# Изменения конфигурации
Новых обязательных переменных окружения не требуется.

# Обработка ошибок
- Некорректное время напоминания должно давать понятную ошибку.
- Отсутствующий или пустой список напоминаний не должен ломать работу.
- Если валютный API недоступен, ошибка должна быть понятной.
- Если в JSON есть устаревшие или частично битые записи, загрузка должна либо нормализовать их, либо явно сообщать об ошибке.

# Последствия для безопасности
- Напоминания хранятся локально в JSON и не выходят за пределы workspace.
- Валютный инструмент только читает внешний публичный API.
- Новые инструменты не должны расширять доступ к shell или файловой системе.

# План проверки
- Проверить создание, список, отмену и срабатывание напоминаний.
- Проверить поведение повторяющихся напоминаний после срабатывания.
- Проверить получение курсов `EUR/USD/RUB`.
- Проверить сохранение напоминаний после перезапуска.
- Проверить CLI-вывод просроченных напоминаний.
