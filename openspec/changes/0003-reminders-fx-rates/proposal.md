# Проблема
Агент уже умеет web search, файлы, терминальные команды, погоду и криптовалюту, но не умеет работать с напоминаниями по расписанию и не умеет получать обычные валютные курсы для `EUR`, `USD`, `RUB`.

# Цель
Добавить два новых пользовательских сценария:
- создавать и сопровождать напоминания, включая повторяющиеся;
- получать актуальные курсы обычных валют.

# Область работ
- `agent/tools.py`
- `agent/agent.py`
- `agent/run.py`
- `agent/reminders.json`
- `tests/*`
- `README.md`
- `openspec/project.md`

# Вне области
- полноценный фоновой daemon или system service;
- сложный cron-синтаксис;
- многопользовательская синхронизация;
- внешняя БД;
- финансовые операции и переводы.

# Пользовательское поведение
- Пользователь может попросить создать напоминание на конкретное время.
- Пользователь может создать повторяющееся напоминание с фиксированным интервалом.
- Напоминания сохраняются в JSON и переживают перезапуск агента.
- При следующем запуске или следующем запросе агент показывает просроченные напоминания и обновляет расписание повторяющихся.
- Пользователь может запросить список активных напоминаний и отменить отдельное напоминание.
- Пользователь может запросить курс одной или нескольких обычных валют.

# Риски
- Без фонового процесса напоминания не будут появляться, пока агент не запущен.
- Простая модель с фиксированным интервалом может не покрыть все сценарии календарного расписания.
- Валютный API может вернуть актуальные данные только для последнего рабочего дня.

# Критерии приёмки
- Есть инструменты для создания, перечисления и отмены напоминаний.
- Напоминания пишутся в JSON и не теряются после перезапуска.
- Повторяющиеся напоминания автоматически переносятся на следующий интервал после срабатывания.
- Есть инструмент получения курса обычных валют.
- Актуальные напоминания и курсы можно получить через CLI агента.
