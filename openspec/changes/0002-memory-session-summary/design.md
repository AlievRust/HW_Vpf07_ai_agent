# Текущее состояние
`MemoryStore.append()` сохраняет в `memory.json` поля `user`, `assistant`, `summary` и `tools`. Из-за этого в долговременную память попадает не только резюме.

В prompt передаётся только долговременная память, но нет отдельного списка последних вопросов текущей сессии. Резюме ответа не отделено от пользовательского вывода настройкой.

# Целевое состояние
Агент работает в двух уровнях памяти:

1. Долговременная память
- хранит только `timestamp`, `summary` и `tools`;
- не хранит полный текст диалога;
- при необходимости может быть очищена от старых лишних полей при записи.

2. Краткосрочная память сессии
- хранит последние N вопросов пользователя;
- существует только в памяти процесса;
- N задаётся через `.env`;
- включается в prompt как контекст текущего диалога.

Также:
- основной ответ и краткое резюме разделяются;
- показ резюме после ответа управляется флагом из `.env`.

# Изменения модели данных
`memory.json`:
- `timestamp`: строка ISO-8601;
- `summary`: краткое резюме взаимодействия;
- `tools`: список использованных инструментов.

Старые поля `user` и `assistant` больше не сохраняются.

# Изменения API
Добавляются или уточняются переменные окружения:
- `SHOW_MEMORY_SUMMARY` - показывать ли резюме после ответа;
- `SHORT_TERM_MEMORY_LIMIT` - сколько последних вопросов хранить в сессии;
- существующие `OPENAI_API_KEY`, `OPENAI_BASE_URL`, `OPENAI_MODEL`, `WORKSPACE_ROOT` остаются без изменений.

CLI остаётся прежним.

# Изменения конфигурации
- `SHOW_MEMORY_SUMMARY=true|false`, по умолчанию `true` для совместимости с текущим поведением.
- `SHORT_TERM_MEMORY_LIMIT` - положительное целое число, по умолчанию `10`.

# Обработка ошибок
- Если модель не вернула отдельное резюме, агент должен использовать безопасный fallback, чтобы не падать.
- Если в `memory.json` есть старые записи с лишними полями, новая запись должна нести только новый формат; при желании можно нормализовать файл при сохранении.
- Некорректные значения env должны давать понятную ошибку или использовать дефолт, если это безопасно.

# Последствия для безопасности
- В долговременную память не сохраняется полный текст диалога.
- Краткосрочная память живёт только в процессе и не переживает перезапуск.
- Показ резюме на экран не влияет на сохранение памяти.

# План проверки
- Проверить, что новая запись в `memory.json` содержит только `summary` и `tools`.
- Проверить, что вывод резюме можно отключить через `.env`.
- Проверить, что список последних вопросов ограничивается `SHORT_TERM_MEMORY_LIMIT`.
- Проверить, что после перезапуска краткосрочная память сбрасывается.
