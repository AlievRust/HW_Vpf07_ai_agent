# Проблема
В репозитории пока нет рабочего терминального AI-агента. Есть только описание идеи, но нет кода, CLI, инструментов, памяти и безопасной интеграции с OpenAI-совместимым API.

# Цель
Создать Python 3.10+ CLI-агента, который работает через OpenAI-совместимый интерфейс, понимает задачи на естественном языке, сам выбирает подходящий инструмент, выполняет ограниченные внешние действия и сохраняет долговременную память в `memory.json`.

# Область работ
- `agent/agent.py` — логика агента и оркестрация инструментов.
- `agent/tools.py` — инструменты для поиска, HTTP-запросов, файловой системы, терминальных команд, погоды и криптовалюты.
- `agent/run.py` — CLI для запуска агента.
- `agent/memory.json` — долговременная память.
- `agent/.env` — локальная конфигурация API.
- проектные метаданные и документация, если они нужны для запуска и проверки.

# Вне области
- графический интерфейс;
- многопользовательская синхронизация памяти;
- фоновые сервисы;
- неограниченный shell-доступ;
- автоматическое управление секретами в продакшене;
- интеграция с дополнительными провайдерами, кроме указанного OpenAI-совместимого интерфейса.

# Пользовательское поведение
- Агент запускается из терминала.
- Пользователь вводит задачу на естественном языке.
- Агент выбирает одно или несколько подходящих действий:
  - веб-поиск;
  - погодный запрос;
  - запрос цены криптовалюты;
  - ограниченную команду терминала;
  - чтение или запись файла;
  - HTTP-запрос.
- Если контекста недостаточно, агент задаёт уточняющий вопрос.
- После ответа агент добавляет краткое резюме диалога в `memory.json`.
- Агент возвращает структурированный, понятный ответ на русском языке.

# Риски
- Небезопасный shell-доступ, если ограничение команд будет слишком слабым.
- Несовместимость версии библиотек `openai` и `langchain`.
- Сбои внешних API погоды, крипты или поиска.
- Рост `memory.json`, если не ограничить формат и размер записей.

# Критерии приёмки
- Есть рабочий CLI-запуск агента.
- Есть инструменты для поиска, HTTP, файловой системы, терминала, погоды и крипты.
- Есть безопасное ограничение терминальных команд.
- Есть чтение и запись долговременной памяти в `memory.json`.
- Есть конфигурация через `.env` для OpenAI API и base URL.
- Есть проверка, что агент корректно обрабатывает запросы про погоду и криптовалюту.
- Есть проверка, что артефакты проекта собираются и импортируются без ошибок.
